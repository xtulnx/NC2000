# NC2000 Android 原生应用项目简报

## 已确认目标

- 首个平台为 Android 原生应用。
- 复用现有 C++ 模拟器核心、SDL2 显示和音频能力。
- Android 界面使用 Kotlin/Jetpack Compose，通过 JNI 调用模拟器核心。
- 支持横屏、竖屏独立键盘布局。
- 默认交互优先照顾竖屏使用，横屏同样支持；两种方向的布局均允许分别自定义。
- 支持全键盘、迷你键盘和游戏专用键盘。
- 支持可命名的“控制场景”：例如游戏模式可在 LCD 周围自由放置矩形、圆形或其他样式的虚拟按键。
- 支持按键位置、尺寸、外观、透明度、标签和行为自定义。
- 虚拟按键行为支持单键、组合键、按住加速、锁定加速和打开运行菜单等动作。
- 支持键盘布局和皮肤的导入、导出及分享。
- 支持运行速度调节、按住加速和锁定加速。
- 提供类似启动器的可编辑启动配置：可为不同 ROM、机型和功能组合建立独立入口，并支持添加、删除、排序和自定义图标。
- 启动配置使用可视化表单编辑，应用内部再映射为模拟器启动参数；不要求用户直接编写 CLI 参数。
- 支持 ROM、应用文件、存档的导入和导出。
- 文件目录采用“软映射”：扫描 Android 授权目录，通过文件级导入、导出和同步连接文曲星虚拟路径。
- NAND 内部继续使用完整镜像，不把普通文件直接绑定到物理 NAND 块。
- ROM/NOR/NAND/NAND0 只作为用户导入内容或本地开发测试资料，不随应用打包，也不提交到 Git；具体 ROM 版本不应耦合应用架构。

## 首版实施顺序

1. 建立 Gradle、NDK、CMake 和 SDL2 Android 工程。
2. 将现有模拟器入口拆分为可由 JNI 控制的核心生命周期接口。
3. 完成 ROM 启动、LCD 显示、声音、暂停和恢复。
4. 完成基础全键盘、横竖屏布局和按键事件桥接。
5. 增加布局编辑器、迷你键盘、皮肤和布局配置文件。
6. 增加运行加速、即时存档和自动保存。
7. 增加可视化启动器和启动配置管理，将机型、ROM 及其他特性映射到核心启动参数。
8. 增加文件导入、导出、批量操作和软映射目录同步。

## 建议默认值

- 应用名称：`NC2000 Emulator`（可修改）。
- Android applicationId：`io.github.wangyu.nc2000`（发布前确认）。
- minSdk：26。
- targetSdk：使用本地 Android SDK 支持的最新稳定版本。
- ABI：首版 `arm64-v8a`，开发阶段可增加 `x86_64` 模拟器支持。
- UI：Jetpack Compose。
- 本地配置：DataStore；布局文件使用带版本号的 JSON。
- 启动配置：使用带版本号的结构化配置保存，不直接持久化任意 CLI 字符串；内置配置和用户配置均可作为启动器入口。
- 用户文件访问：Storage Access Framework，不申请全盘存储权限。

## 开始开发前最重要的资料

### 必需或强烈建议

1. 至少一套确认能够在当前桌面版启动的 ROM、NOR、NAND/NAND0 文件。固件不提交到公开仓库，只用于本地测试。
2. 对应的桌面启动命令、机型和 ROM 版本，例如 NC2000、NC2600 或 NC1020。
3. 一个可用于验证导入、运行和导出的文曲星应用文件，例如 `.bin` 文件。
4. 首版优先支持的机型和 ROM 版本。
5. 桌面版现有命令行参数清单、默认值、互斥关系，以及各参数对应的 ROM、机型和功能含义，用于设计可视化配置项。

### 当前开发基线

- 首个验证机型：NC1020 官方 3.6。
- 桌面基线参数：`--nc1020 --rom roms/nc1020`，不启用自动保存。
- `.bin` 应用文件导入、运行和导出测试暂缓，不阻塞工程脚手架和核心生命周期改造。

### 当前工程进度

- Android Compose 启动器、结构化启动配置、DataStore 持久化和 SAF 固件选择已建立。
- SDL2 2.32.10 已固定为 Git 子模块，并完成 `arm64-v8a`、`x86_64` 编译和模拟器动态加载验证。
- 桌面入口已改为通过可复用 `EmulatorSession` 管理初始化、暂停、恢复、省电、停止和保存，NC1020 桌面基线验证通过。
- CPU、内存、ROM/NOR/NAND、DSP、声音生成、命令、按键矩阵和会话源码已纳入 Android 双 ABI 编译。
- JNI 已启动共享核心工作线程，并接入暂停、恢复、停止、自动保存及前后台生命周期。
- Android 已显示 160×80 点阵主屏和原桌面版 LCD 段码/状态指示符区，NC1020 主界面验证通过。
- 基础触摸键盘已接入新旧按键矩阵，并为短按事件提供最小有效扫描时长。
- 已提供可切换的默认迷你键盘和全键盘；竖屏可滚动，横屏使用 LCD 与键盘并排布局。
- 已增加运行时菜单，可切换屏幕效果和锁定快速播放，并请求复位、手动保存及返回启动器；键盘支持按住临时加速。
- SDL AAudio 设备已在 Android 模拟器成功打开；蜂鸣器和 DSP 实际听感仍需人工验证。
- 已持久化可命名控制场景和横竖屏独立布局，并提供位置、尺寸、矩形/圆形、透明度、标签和动作映射的可视化编辑器。
- 启动入口可选择控制场景；运行时会按当前方向渲染虚拟按键，并支持单键、组合键、按住加速、锁定加速和打开运行菜单。
- 控制场景可选择简洁 LCD 边框或带斜纹、层次边线和编号标记的经典机身边框；运行菜单也可临时切换。
- 下一步增加场景和皮肤的导入、导出、分享，以及更完整的外观编辑能力。

## 测试验收基线

- 同一套 ROM 在桌面版和 Android 版能够进入相同主界面。
- LCD 内容、时间、按键、蜂鸣器和 DSP 发音行为一致。
- 应用前后台切换不会损坏 NAND 或即时存档。
- 导入后文件可以在文曲星中打开，导出后与原始内容一致。
- 横竖屏切换不会丢失按键状态或破坏自定义布局。
- 用户可以通过可视化界面新增、复制、编辑、删除和排序启动配置，为配置选择图标，并从启动器直接进入对应 ROM 和功能组合。
- 启动配置生成的核心参数与等价桌面启动命令行为一致，非法或冲突配置会在启动前提示，而不是拼接任意命令行文本。
