# Android UI 素材清单

本目录用于存放从第四版视觉稿还原出的生产素材。当前尚未生成最终素材；新会话应先实现 Compose 基础形状，再判断哪些纹理确实需要位图。

## 推荐保留为代码绘制

- 键帽底色、圆角、描边和阴影
- 按下、禁用、选中状态
- 键帽主体文字和外部辅助文字
- 银灰面板底色与分割线
- 模式选择器、底部面板和普通卡片

## 可能需要的透明素材

只有在纯 Compose 效果过于平坦时再制作：

| 文件建议名 | 格式 | 内容 | 限制 |
| --- | --- | --- | --- |
| `keycap-texture.webp` | 无损 WebP + Alpha | 极淡磨砂颗粒 | 无文字、无固定底色、可平铺 |
| `keycap-highlight.webp` | 无损 WebP + Alpha | 键帽顶部微弱高光 | 无阴影、可缩放 |
| `panel-noise.webp` | 无损 WebP + Alpha | 银灰面板细颗粒 | 不得形成明显照片纹理 |
| `lcd-glare.webp` | 无损 WebP + Alpha | 可选 LCD 反光 | 默认关闭，不影响像素可读性 |

设计母版可使用透明 PNG，确认后再转换为 Android 无损 WebP。禁止从 `nc1020-ui-concept-v4.png` 直接裁切后作为生产素材。

## 矢量图标

以下图标使用 Vector Drawable 或 Compose Icons，不使用位图：

- 加速：双箭头
- 存档：保存
- 读档：打开文件夹
- 菜单：更多
- 返回、运行状态、结束模拟器

## 验收

- 透明素材四角 Alpha 为 0，没有白边或背景色残留。
- 素材本身不包含中文、英文或数字文字。
- 纹理叠加前后不会降低键帽文字对比度。
- 不依赖单一屏幕密度；至少在 360dp 和 600dp 宽度下无明显拉伸。
